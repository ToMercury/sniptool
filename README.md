# Sniptool

**Sniptool** 是一款专为 Linux 桌面环境深度定制的轻量级、高性能截图与剪贴板增强工具。界面优雅圆角、启动敏捷流畅、原生适配多屏与高分屏，提供开箱即用的现代化桌面体验。

---

## 快速上手

### 1. 运行依赖

- 操作系统：Linux（已完整测试适配 Debian 13、Xfce 4.20、X11 环境）
- 解释器：Python 3.10+
- 核心依赖：PySide6 (Qt 6), python-xlib, tesseract-ocr
- 推荐安装系统依赖：
  ```bash
  sudo apt install -y tesseract-ocr tesseract-ocr-chi-sim tesseract-ocr-eng tesseract-ocr-osd
  ```

### 2. 启动与常驻

项目自带便捷执行入口 `./sniptool`：

```bash
# 1. 启动常驻后台服务（自动脱离终端在后台运行，不占用终端）
./sniptool            # 或 ./sniptool daemon

# 2. 命令行快速调出对应功能
./sniptool capture      # 立即触发截图
./sniptool clipboard    # 呼出剪贴板历史面板
./sniptool settings     # 打开设置中心

# 3. 退出后台服务
./sniptool quit
```

## 快捷键速查表

| 场景 | 快捷键 / 交互 | 功能说明 |
| :--- | :--- | :--- |
| **全局** | `Ctrl + Alt + A` | 唤起截屏遮罩 |
| | `Super + V` | 唤起剪贴板历史面板 |
| **截屏遮罩** | 鼠标左键拖拽 | 框选截屏区域 |
| | 8 方向控制手柄 | 缩放/调整选区边缘 |
| | 方向键（`↑ ↓ ← →`） | 1px 像素级微调选区（按住 `Shift` 加速为 10px） |
| | `Enter` / `Ctrl + S` | 保存截图到指定目录并关闭 |
| | `Ctrl + C` | 复制截图至剪贴板并关闭 |
| | `Shift + C` | 对选区执行 OCR 文字识别并自动复制 |
| | `Ctrl + T` | 对选区文字执行 DeepSeek 智能翻译 |
| | `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做上一步标注操作 |
| | `Delete` / `Backspace` | 删除当前选中的标注项 |
| | `Esc` | 退出当前标注工具 -> 清除选区与标注 -> 退出遮罩 |
| **标注交互** | 单击文字/矩形/箭头 | 选中该标注，显示操作手柄与虚线框 |
| | 鼠标滚轮（选中状态） | 向上放大、向下缩小，等比例调整大小与线宽/字号 |
| | 标注文字状态下打字 | 输入框根据字数自动向右延展，限制在选区内 |
| | 双击已有文字 | 直接重新打开编辑框修改文本内容 |
| **贴图 (Pin)** | 双击图片 / `Esc` | 关闭贴图窗口并释放资源 |
| | 鼠标滚轮 / 拖拽边框 | 等比例放大/缩小贴图 |
| | 鼠标右键 | 打开贴图右键菜单（复制、另存为、预设缩放、关闭） |
| **剪贴板面板** | `↑` / `↓` | 浏览切换历史项目 |
| | `Space`（空格） | 对当前选中记录切换收藏状态（自动归入收藏视图） |
| | 双击 / `Enter` | 复制并立即粘贴回原活动窗口 |
| | `Delete` | 删除该条历史记录（光标原地保持） |
| | 点击「清空」 | 一键清空所有未收藏记录（收藏项自动保留） |
| | `Esc` | 关闭剪贴板历史面板 |
